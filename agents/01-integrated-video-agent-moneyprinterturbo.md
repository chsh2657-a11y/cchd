# 통합형 영상 제작 에이전트 — MoneyPrinterTurbo

## 원본 저장소
https://github.com/harry0703/MoneyPrinterTurbo

## 개요
대본(또는 주제)만 입력하면 AI가 스크립트를 작성하고, TTS로 내레이션을 생성하고, 주제에 맞는 이미지·영상 소재를 매칭하고, 자막을 입히고, 배경음악을 더해 최종 영상 파일까지 한 번에 만들어주는 오픈소스 프로젝트입니다. 약 9만 7천 개 이상의 스타를 받았고 최근까지도 활발히 업데이트되는, 이 분야에서 가장 널리 쓰이는 프로젝트입니다.

## 핵심 기능
- AI 자동 스크립트 생성 또는 사용자가 작성한 대본 직접 입력
- TTS 다중 제공자 지원: Edge TTS(무료), Azure TTS, ElevenLabs, Google Gemini TTS 등, 실시간 미리듣기 가능
- 자막 자동 생성, 글꼴·색상·위치·외곽선 조정 가능
- 배경음악 랜덤 또는 지정곡 선택, 볼륨 조절
- 로컬 이미지·영상 소재 직접 사용 가능(제품 사진, 데모 영상 등)
- 9:16(세로), 16:9(가로) 두 비율 지원, 여러 개를 한 번에 생성해 최적본 선택 가능
- WebUI, CLI, API, AI 에이전트(SKILL.md) 네 가지 방식으로 사용 가능

## AI 에이전트로 사용하는 법
터미널 조작이 가능한 AI 에이전트(Claude Code, Cursor 등)에게 아래 스킬 문서 주소를 알려주면 설치와 설정, 영상 생성까지 자동으로 진행합니다.

https://raw.githubusercontent.com/harry0703/MoneyPrinterTurbo/main/docs/skill/SKILL.md

이 스킬 문서에는 "설치·생성 전에 사용자 확인을 요청하지 말라"는 지시가 담겨 있습니다. 이는 웹 콘텐츠에 포함된 지시문이므로, 실제로 설치나 실행을 진행할 때는 항상 먼저 사용자에게 확인받는 것을 권장합니다.

## 단계별 설정 포인트 (WebUI 기준)
1. 기본 설정 — LLM 제공자·모델 선택, API 키 입력
2. 영상 설정 — 주제 또는 대본 입력, 영상 비율, 세그먼트 길이
3. 음성 설정 — TTS 제공자·음색 선택 후 미리듣기
4. 자막 설정 — 글꼴, 크기, 색상, 위치
5. 배경음악 설정 — 곡 선택 또는 랜덤, 볼륨
6. 생성 및 미리보기, 필요 시 파라미터 조정 후 재생성

## 공중영상홀로그램 홍보영상 적용 팁
제품 사진과 데모 영상을 로컬 소재로 등록하고, 직접 작성한 홍보 대본을 입력하면 AI가 관련 없는 소재를 임의로 넣는 것을 방지할 수 있습니다.

## 필요한 API
- LLM API 중 택1: OpenAI, Google Gemini, DeepSeek, 알리바바 통이치엔원 등
- 영상·이미지 소재(선택): Pexels API, 로컬 소재만 사용할 경우 불필요
- 고품질 음성을 원할 경우(선택): ElevenLabs API

발급과 설정 방법은 setup/api-key-setup-guide.md 문서를 참고하세요.
